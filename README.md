# PrepPilot

Track DSA practice, spot weak topics, and get a daily study plan for coding interviews.

- Stack: HTML, CSS, vanilla JavaScript (no build step, no dependencies)
- Storage: browser localStorage only. No backend, no accounts, no API keys.
- Study planner: rule-based and computed locally. It is not an AI model.

## Run locally
Open `index.html` in any modern browser.

## Deploy free
- Netlify Drop: drag this folder onto https://app.netlify.com/drop
- GitHub Pages: push to a repo, then Settings > Pages
- Cloudflare Pages: upload the folder

## Known limitations
- Data lives in one browser on one device (no sync, no export yet).
- Streaks count any entry, including attempted and demo ones.
